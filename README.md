# Exercícios de Python

Exercícios e anotações das aulas dos cursos de Python que estou fazendo. Mostra a minha evolução na linguagem, do básico às funções.

## Conteúdo

### `academify/modulo03_logica_de_programacao`
Lógica de programação: variáveis, `input`, conversão de tipos, `try/except`, condicionais, laços `while` e `for`, listas, tuplas e dicionários.
Atividades: média de notas, par ou ímpar, desconto e aumento de preço, palíndromo, tabuada, calculadora e lista de notas.

### `academify/modulo04_funcoes`
Funções: parâmetros, `*args`, `return`, escopo de variáveis (exemplo de depósito em conta), recursão e funções `lambda` (calculadora simples).

### `guanabara`
Exercícios do curso de Python do Gustavo Guanabara (Curso em Vídeo), do 19 ao 25: sorteio e ordem de alunos com `random`, tocar um MP3 com `pygame`, manipulação de textos, separar os dígitos de um número e procurar palavras dentro de textos.

## Como rodar

```bash
python3 academify/modulo04_funcoes/calculadora_simples.py
```

O `exercicio21.py` precisa da biblioteca `pygame` (`pip install pygame`) e de um arquivo `rise.mp3` na mesma pasta.
